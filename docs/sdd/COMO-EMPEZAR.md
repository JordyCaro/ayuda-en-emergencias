# Cómo empezar (developers)

1. Lee [`../MAPA-DEL-REPO.md`](../MAPA-DEL-REPO.md) — front vs back vs infra.  
2. Lee la [constitution](../../.specify/memory/constitution.md).  
3. Abre el slice activo: [`../../specs/001-mvp-mapa-ayuda/`](../../specs/001-mvp-mapa-ayuda/).  
4. Orden: `spec.md` → `plan.md` → marca tareas en `tasks.md`.  
5. No escribas código hasta que el equipo apruebe spec+plan y avances Fase 0 (fuentes).

Flujo completo: [`workflow.md`](workflow.md).
